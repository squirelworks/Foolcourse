# Future

## Foolcourse v1.x

Make the official list a property of the deployment in every path, not
only when a curriculum file is passed.

- The curriculum maker is the normal way to name a list.
- A second deployment points at its own folder and its own file, with
  no ATT names anywhere.
- The window labels the track by the list's name.

## Foolcourse v2.0.0

More than one curriculum in one catalog.

- Each official list has its own overall.
- Extra material can be grouped: supplements, drills, outside reading.
  Grouping does not make it official.
- Progress and scores travel with the learner, not with one curriculum.

## Foolversity

Grows into the administration side only as far as the files need.

- Student files and school files are the start.
- A later module can make the `.fcs` seal real. The envelope stays.
- Curriculum creation stays here. Foolcourse reads the result.

## Foolbook

Done in 1.0.8: polygons, bounds, and pictures drawn for the page on screen. Quizzes read from a raw `.tbk`.

Still open:

- System books used as a runtime shell, not only as a jump target.
- A `.tbk` the ToolBook 8.1 engine will open. See
  [07_toolbook.md](07_toolbook.md).

## The rule that does not change

Official counts. Extra is kept, scored, and left out of the overall.
That rule is the platform. Everything else is a way of naming the list.
